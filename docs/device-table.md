# 機種ごとのスクショの大きさと、ステータスバーの位置（Simulator での実測）

- 測った日: 2026-11-12。Xcode 26.6 の Simulator（iOS 18.6 / 26.5 / 27.0 / 27.1）
- 撮り方: `Tools/statusbar/capture.sh`（一時的な Simulator を作り、`simctl status_bar override` で 9:41・電波 4 本・Wi-Fi 3 本・電池 100% にして、設定アプリを撮る）。撮った画像（168 枚・約 130MB）はリポジトリに入れず、上端だけを切り出したものをテストのフィクスチャ（`Packages/BarlessKit/Tests/BarlessTestSupport/Fixtures/`）に置いている
- 測り方: `Tools/statusbar/analyze.py`（上端から、背景と違う色の画素を拾う）。数値の元は `docs/device-table.json`
- この表は `Tools/statusbar/build-table.sh` で作り直せる（手で直すときは `Tools/statusbar/device-table.head.md` を直す）。手順は [Tools/statusbar/README.md](../Tools/statusbar/README.md)

## 0. 分かったこと

1. **スクショの大きさだけでは、配置が 1 つに決まらない機種がある**
   - 1206×2622: iPhone 17 と iPhone 18 Pro で、時刻と右側のアイコンの位置が違う（時刻の左端が 57pt と 64pt）
   - 1320×2868: iPhone 18 Pro Max（Simulator）と **iPhone 16 Pro Max（実機）** でも違う（時刻の左端が 73pt と 65pt、電波の左端が 302pt と 312pt）
   - 1170×2532: iPhone 12・16e・17e は同じ配置
   - 1179×2556: iPhone 15・16 は同じ配置
   - → 大きさで候補を絞った後、**時刻の位置（文字認識の結果）でどの配置かを決める**必要がある
2. **iOS 18 と 26 はほぼ同じ配置で、iOS 27 で大きさと位置が変わっている**（配置の世代は「iOS 18〜26」と「iOS 27」の 2 つで足りる見込み）
   - iOS 18.6 と 26.5 は、撮った 10 機種すべてで位置の差が 0.5pt 以内
   - ノッチの機種（iPhone 12・16e・17e、13 mini、14 Plus）: iOS 27 では時刻が約 10pt 右に寄り、文字とアイコンが 1〜2pt 大きい
   - Dynamic Island の機種（15・16・17・Air など）: 位置はほぼ同じで、文字とアイコンが約 1pt 大きい
   - iPhone 11 系と SE: ほぼ変わらない
   - → 配置の表は「機種のグループ × iOS の世代」で持つ。**画像から iOS の世代を見分ける処理**も要る（時刻の位置と大きさで判定できる見込み）
3. **iPhone Air は 1260×2736**（2740 ではなかった）。文字とアイコンの位置がほかの機種より下（上端から約 31pt）
4. **iPhone Duo（1398×2034）は別の配置**。時刻などが画面の右上に縦に並び、ほかの機種の「上端に横 1 列」と違う。MVP の対象から外し、手動調整に回す
5. iPhone 11・13 mini・SE は、アイコンどうしの間が 4.5〜5pt と狭い（ほかの機種は 5.3pt 以上）。要素を分けるすき間のしきい値を 3pt にして測っている（要素の中のすき間は 2pt 以下）。SE は時刻が中央にあり、左に電波・キャリア名・Wi-Fi、右に電池が並ぶ
6. スクショは四隅の数 px が黒く欠けることがある（Simulator、Mac 側で撮った画像）。本体で撮った画像は欠けない。判定に四隅を使わない

## 実機での確認（2026-11-12）

- **iPhone 16 Pro Max（iOS 27.2）には「拡大表示」の項目が見当たらなかった**（設定 → 画面表示と明るさ、アクセシビリティ → 画面表示とテキストサイズの両方を利用者が確認）。iOS 27 で無くなったのか、この機種だけなのかは未確認。XS・XR（iOS 18）と 12 mini・13 で確かめる
- 何も表示していない Dynamic Island は、スクショに写らない（ステータスバーの中央は背景だけ）
- 電池の % 表示がオフのとき、残量は塗りの幅だけで表される
- **iPhone 16 Pro Max・iOS 27.2・標準表示・ライトの実測**（元の画像は名前が写っているのでリポジトリに入れていない。1320×2868）: 文字とアイコンの上下 24.7〜39.7pt、時刻 65, 26, 37.3×13.3 / 電波 312.3, 24.7, 21.7×14.3 / Wi-Fi 341, 24.7, 20×14.3 / 電池 368.3, 25.3, 31.3×14.3（pt。時刻は「3:20」）
- 本体で撮った元の画像 2 枚（ライト・ダーク、時刻は「3:16」）も測った。上端 80pt だけを切り出して `Packages/BarlessKit/Tests/BarlessTestSupport/Fixtures/realshots/16ProMax_iOS27.2_std-{light,dark}_top.png` に保存（名前などが写らないようにするため）
  - **ライトとダークで位置はまったく同じ**（色だけが反転する）
  - **時刻は中央ぞろえ**: 「3:16」は左端 66.3pt・幅 35pt、「3:20」は左端 65pt・幅 37.3pt で、どちらも中心が約 83.7pt。描き直すときは左端ではなく中心で合わせる
  - 右側のアイコン（電波 312.3 / Wi-Fi 341 / 電池 368.3）は 3 枚とも同じ位置
- **本体で撮った画像の四隅は欠けていなかった**。3:20 の画像（Mac 側で保存されたファイル名）だけ四隅が 7px 黒く欠けていた。撮り方で四隅の有無が変わるので、判定に四隅を使わない方針は変えない

## まだ測れていないこと
- 「文字を太くする」（アクセシビリティ）をオンにしたときの時刻の太さ

- 拡大表示モード（実機が必要）
- Dynamic Island にライブ表示が出ているとき
- ダークモードと電池が少ないときの画像（撮ってあるが、まだ測っていない）
- 16 Pro・17 Pro など、今回撮っていない機種
- iPhone XS・XS Max・XR は、手元の Simulator（iOS 18.6 / 26.5 / 27.0）では作れなかった。実機（XS・XR）で撮る
